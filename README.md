### 📋 Overview

AI-IT-Helpdesk-Agent is an intelligent IT helpdesk automation system that uses AI/ML to classify IT issues, auto-generate support tickets, and provide instant solutions to common problems. It reduces manual effort for IT support teams and improves resolution time.

### ✨ Key Features

- **Automated Issue Classification:** Classifies user queries (Hardware, Software, Network, Access Issue)
- **Intelligent Ticket Management:** Auto-creates tickets with priority (Low, Medium, High, Critical)
- **AI-Powered Response:** Provides instant solutions from knowledge base
- **Workflow Automation:** Automates L1 support tasks
- **Dashboard & Analytics:** Tracks ticket status and resolution metrics

### 🛠️ Tech Stack

- **Backend:** Python, Flask / FastAPI
- **AI/ML:** NLP (Natural Language Processing), Intent Classification, LLM
- **Database:** SQLite / MySQL / MongoDB
- **Frontend:** HTML, CSS, JavaScript (or Streamlit / React)
- **Tools:** Git, GitHub
